# 安全政策 · Security Policy

## 报告安全问题 / Reporting a vulnerability

请不要在公开 Issue 中披露仍可被利用的安全问题。请使用 GitHub 仓库的 **Security → Report a vulnerability** 私下提交报告，并说明影响、复现步骤与建议修复方式。

Do not disclose an exploitable vulnerability in a public issue. Use the repository's **Security → Report a vulnerability** flow and include the impact, reproduction steps, and any suggested remediation.

暮光起始页不会收集遥测信息，因此安全报告中请仅提供复现问题所需的最少数据。

Twilight Start Page does not collect telemetry. Include only the minimum data required to reproduce the issue.
