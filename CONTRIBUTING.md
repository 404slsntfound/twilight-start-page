# 参与贡献 · Contributing

感谢你帮助改进暮光起始页。Bug、功能建议和代码贡献均可通过 GitHub 提交。

Thank you for helping improve Twilight Start Page. Bug reports, feature requests, and code contributions are welcome through GitHub.

## 提交问题 / Opening an issue

- Bug 请附上 Chrome 版本、扩展版本、复现步骤和截图。
- 功能建议请说明使用场景和期望行为。
- 提交前请先搜索现有 Issues，避免重复。

- For bugs, include your Chrome version, extension version, reproduction steps, and screenshots.
- For feature requests, describe the use case and expected behavior.
- Search existing issues before opening a new one.

## 本地开发 / Local development

1. Clone or download the repository.
2. Open `chrome://extensions/`.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the repository directory.
5. After changing files, reload the extension from `chrome://extensions/`.

## Pull requests

- 保持改动聚焦，并在提交说明中解释原因。
- 界面改动请附上修改前后的截图。
- 不要提交个人书签、浏览数据或其他敏感内容。
- 确保扩展能够在当前稳定版 Chrome 中正常加载。

- Keep each change focused and explain the motivation.
- Include before and after screenshots for interface changes.
- Do not commit personal bookmarks, browsing data, or other sensitive content.
- Verify that the extension loads in the current stable Chrome release.
