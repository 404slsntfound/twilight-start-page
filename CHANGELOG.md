## [1.5.9] - 2026-09-22

首个公开版本。 / First public release.

### 新增 / Added

- Safari 风格的新标签页、书签和分组布局。
- Safari-inspired new tab, bookmark, and group layout.
- 网站官方图标发现、Google 官方 favicon 与自定义图标。
- Official-site icon discovery, Google favicon option, and custom icons.
- Safari 风格右键菜单、拖动排序和玻璃拟态编辑面板。
- Safari-style context menus, drag sorting, and glass edit panel.
- 自定义背景和本地优先存储。
- Custom backgrounds and local-first storage.
- Safari 与 Chrome 书签 HTML 导入导出。
- Safari and Chrome bookmark HTML import and export.
